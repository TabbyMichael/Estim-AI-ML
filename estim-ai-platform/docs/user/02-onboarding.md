# Estim AI Platform - Onboarding Guide

## 1. Welcome to Estim AI Platform

This guide walks you through your first steps with the Estim AI Platform. By the end, you should be able to:

- Log in and navigate the dashboard
- Understand the main modules
- Create or update basic data
- Access help resources

## 2. Prerequisites

Before you begin:

- You have received your login credentials from an administrator
- You have access to the platform URL
- You have a user account with appropriate role (admin, manager, or staff)

## 3. First Login

### 3.1 Access the Platform

1. Open your browser
2. Navigate to the platform URL (contact your administrator if unsure)
3. Enter your email and password
4. Click "Sign In"

### 3.2 Complete Profile Setup

After logging in for the first time:

1. Click your profile icon in the top-right corner
2. Select **Profile**
3. Verify your name and email
4. Set your time zone
5. Configure your notification preferences
6. Save changes

### 3.3 Accept Terms (if required)

Some organizations require accepting terms of use:

1. Navigate to **Settings** → **Terms**
2. Review the terms
3. Accept to continue

## 4. Module Overview

### 4.1 Dashboard

Your starting point. Shows:

- Key metrics overview
- Recommended actions
- Recent activity
- Upcoming events

**Tip:** Bookmark this page for quick access.

### 4.2 Navigation

Use the main sidebar to navigate:

```
┌─────────────────────────────────────────┐
│ Home │ Procurement │ Cost Forecast │ ... │
└─────────────────────────────────────────┘
```

### 4.3 Your Role

| Role | Access Level | Typical Use |
|------|--------------|-------------|
| **Admin** | Full access | Configuration, user management, system maintenance |
| **Manager** | Owned companies | Data entry, review, approvals |
| **Staff** | Own data | View and edit own data only |

## 5. Quick Start: Your First Task

### 5.1 For Supplier/Staff: Create a Record

**Example: Create a purchase order in Procurement**

1. Navigate to **Procurement**
2. Click **Create Purchase Order**
3. Fill in required fields:
   - Supplier (required)
   - Order date (required)
   - Line items
4. Review and **Save**

### 5.2 For Manager: Review Data

1. Navigate to the module
2. Use filters to narrow down data
3. Click on records to view details
4. Make comments or approval as needed

## 6. Useful Features

### 6.1 Search

Search from anywhere in the platform:

1. Press `Ctrl+K` or click the search icon (top bar)
2. Type your search query
3. Select results from the dropdown

### 6.2 Filters

Many list views support filtering:

1. Click the **Filters** button
2. Add criteria (date range, status, etc.)
3. Apply filters
4. Clear filters when done

### 6.3 Bulk Actions

Apply actions to multiple records:

1. Select records with checkboxes
2. Select **Bulk Actions** from the dropdown
3. Choose action (export, delete, update status)

## 7. Common Tasks by Role

### 7.1 Administrator Tasks

- Create and manage users
- Configure modules
- Monitor system health
- Manage integrations

### 7.2 Manager Tasks

- Approve work orders
- Create forecasts
- Review and annotate invoices
- Generate reports

### 7.3 Staff Tasks

- Enter data
- View assigned tasks
- Create work orders
- Update inventory

## 8. Accessing Help

### 8.1 In-App Help

1. Click the **Help** button in the top bar
2. Browse the online help documentation
3. Search for specific topics

### 8.2 Community Support

- **Slack**: #estim-support channel
- **Feedback**: #estim-feedback channel
- **Lounge**: #estim-lounge (social)

### 8.3 Escalation

If you need help:

1. Try the in-app help
2. Search the documentation
3. Ask in #estim-support
4. Escalate to your team lead

## 9. Security Practices

- Never share your password
- Log out on shared computers
- Report suspicious activity immediately
- Keep your contact information up to date

## 10. Next Steps

After completing onboarding:

1. **Explore**: Spend time in each module
2. **Practice**: Create sample data (test data)
3. **Learn**: Review module-specific documentation
4. **Connect**: Join the team Slack or other communication channels
5. **Upgrade**: Request additional training as needed

## 11. Troubleshooting

| Issue | Solution |
|-------|----------|

| Missing module | Contact admin to check access |
| Can't find menu item | Check role permissions |
| Error messages | Note and report to support |
