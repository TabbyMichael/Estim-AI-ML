# Estim AI Platform - Support Team Training

## Core Skills Checklist
- Log in, manage users, and recognize role/permission errors.
- Capture API request IDs and find related logs/traces.
- Run procurement, forecasting, inventory, and document smoke checks.
- Distinguish data issues from application outages.
- Follow on-call handoff, incident, backup-restore, and migration runbooks.

## Guided Exercises
1. Resolve a locked-out user and explain RBAC.
2. Reproduce an invoice-sync failure and collect Odoo context.
3. Validate a forecast, identify model drift, and escalate retraining.
4. Create a P2 issue, assign labels, and escalate after reproduction.
5. Perform a staging backup/restore dry run.
